重学 Java 数据结构：从裸数组到 ArrayList

1 背景：为什么裸数组扛不住千万 QPS？

2023 年双十一，商品中心缓存集群 QPS 峰值 1200 w；早期为了极致性能直接裸用 Object[] 做本地缓存，结果：

  • 无法动态扩缩容 → 重启一次 3 分钟，流量瞬间打爆下游
  • 删除元素触发 System.arraycopy → GC 停顿 200 ms+
  • 伪共享导致 CPU 利用率上不去（后面会给出 Perf 火焰图）

于是把裸数组升级为「可观测 + 可扩展 + 无伪共享」的定制 ArrayList，单节点 QPS 提升 41%，P99 延迟从 12 ms 降到 3 ms。

8 面试高频追问清单

  1. ArrayList 的默认容量为什么是 10？改成 16 会怎样？

    10 是 JDK1.2 时代根据 “平均应用” 经验值；16 会浪费小负载场景内存，但减少 1 次扩容。

  2. System.arraycopy 是深拷贝还是浅拷贝？

    浅拷贝；仅复制引用，对象本身仍在原地址。

  3. 为什么删除元素后要把末尾设为 null？

    帮助 GC 更早释放，防止内存泄漏。

  4. 说说你对 @Contended 的理解，它为什么默认只能在 JDK 内部使用？

    需开启 -XX:-RestrictContended；过度填充会浪费内存，官方对用户开放持谨慎态度。

  5. ArrayList 和 Vector 的最大区别？

    Vector 所有方法 synchronized，单线程性能差 3~5 倍；ArrayList 非线程安全，需外部同步或使用 CopyOnWriteArrayList。
