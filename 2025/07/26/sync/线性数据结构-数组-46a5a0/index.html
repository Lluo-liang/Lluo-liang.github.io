线性数据结构-数组

文章主题： 线性数据结构-数组

数组

数组是数据结构还是数据类型？

“数组”并不是非得长成内存里一块连续的区域，而是“凡是能提供 a[i] 这种语义的东西，我们都可以叫它数组”

给定一个整数索引 idx，返回一个值 val。只要你能实现这个映射，你就满足了数组的最小语义。

至于这个映射背后是把数据真的放在一块连续内存里，还是放在跳表、哈希表、磁盘上，甚至实时算出来，都不影响它对外呈现的“数组”身份。

当你定义了数据的存储方式，也就定义了数据结构。所以它也是被归类为数据结构

数组数据结构

数组（Array）是一种线性表数据结构。它用一组连续的内存空间，来存储一组具有相同类型数据的集合。

数组的特点：

  1. 数组是相同数据类型的元素集合（int 不能存放 double）
  2. 数组中各元素的存储是有先后顺序的，它们在内存中按照这个顺序连续存放到一起。内存地址连续。
  3. 数组获取元素的时间复杂度为O(1)

一维数组

一维数组是最常用的数组，其他很多数据结构的变种也都是从一维数组来的。例如 HashMap 的拉链寻址结构，ThreadLocal 的开放寻址结构，都是从一维数组上实现的。

二维数组

二维以及多维数组，在开发场景中使用到的到是不多，不过在一些算法逻辑，数学计算中到是可以使用。

实现数组列表

在一些数据存放和使用的场景中，基本也都是使用 ArrayList 而不是 LinkedList

LinkedList插入速度比ArrayList快？你确定吗？

1. 基本设计

数组是一个固定的、连续的、线性的数据结构，那么想把它作为一个自动扩展容量的数组列表，则需要做一些扩展。

  • 初始化 ArrayList 阶段，如果不指定大小，默认会初始化一个空的元素。这个时候是没有默认长度的。
  • 那么什么时候给初始化的长度呢？是在首次添加元素的时候，因为所有的添加元素操作，也都是需要判断容量，以及是否扩容的。那么在 add 添加元素时统一完成这个事情，还是比较好处理的。
  • 之后就是随着元素的添加，容量是会不足的。当容量不足的是，需要进行扩容操作。同时还得需要把旧数据迁移到新的数组上。所以数据的迁移算是一个比较耗时的操作

    private Object[] grow() {
        int oldCapacity = elementData.length;
        int newCapacity = oldCapacity + (oldCapacity >> 1); // 计算新容量
        if (newCapacity - MAX_ARRAY_SIZE <= 0) // 边界检查
            newCapacity = MAX_ARRAY_SIZE;
