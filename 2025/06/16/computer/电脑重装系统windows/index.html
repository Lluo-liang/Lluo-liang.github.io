电脑重装系统windows

前言

由于电脑C盘空间爆炸，同时电脑出现未知弹窗，重装一下电脑系统，并记录一下相关操作。

此次操作只改动电脑C盘，其他空间不处理。

可以参考一下 设备——主机装机#操作系统装机

使用老毛桃的方式进行安装： https://lmt.psydrj.com/udisk.html

（目前暂时没找到纯净方式，官方的下载有点慢，后面再研究了）

目前使用的一些软件，重置后可以再安装一下

重装系统

电脑重新安装的一些步骤：

1、使用老毛桃进行安装,iso 文件官网下载（或者提前备份）

2、驱动使用：驱动修复大师，将显卡驱动升级一下；

3、电脑激活

4、卸载一些软件：包括360 卫士等。

中间过程中下载了几个工具，觉得还不错：

  • DiskGenius 分区工具
  • WinDirStat 磁盘分析工具

Windows磁盘管理

按 Win + X → 选择“磁盘管理”​​。

DiskGenius 使用

  • 右键点击 ​​D盘（软件）​​ → 选择 ​​调整分区大小​​。
  • 在弹出的窗口中，​​拖动D盘左侧边界向右​​，使20GB未分配空间移动到C盘和D盘之间。

分配好后，再使用磁盘管理就行（需要分配空间在 C 盘右边）

Git 的重新安装，直接安装即可（默认方式); 安装完后设置一下邮箱和用户信息，然后再设置一下仓库的 公钥 信息，进行再拉取操作，可以看 Git 的另外一篇文章内容。

基本的环境安装：

  • VSCode
  • Java17 的安装
  • maven环境配置
  • IDEA 安装
