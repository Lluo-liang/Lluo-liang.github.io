新建数据库的时候建议的字符集 (Character Set)选择： utf8mb4 （- 完全支持Unicode，包括emoji表情符号；- MySQL 8.0+ 默认字符集）

排序规则(Collation)建议：

  • ​​中文推荐​​: utf8mb4_general_ci (通用规则，不区分大小写)
  • ​​精确排序推荐​​: utf8mb4_unicode_ci (基于Unicode标准，更准确但稍慢)
  • ​​区分大小写场景​​: utf8mb4_bin (二进制比较，区分大小写)

注意事项

  • MySQL 8.0 默认使用了更强的密码加密策略（caching_sha2_password），某些客户端可能需要更新或配置以支持新的加密方式。
