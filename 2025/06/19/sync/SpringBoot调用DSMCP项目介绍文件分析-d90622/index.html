SpringBoot调用DS——MCP项目介绍文件分析

​​核心主题：​​ 这是一个实现 ​​MCP (Model Context Protocol)​​ 协议的开源项目，主要用于构建一个标准化的中间件（AI应用程序的“USB-C”端口），将AI大模型（如DeepSeek）与你现有的数据源和工具连接起来。项目基于 ​​Spring Boot 3.x​​，使用 ​​Docker​​ 部署。

核心模块与架构

  1. ​​MCP Server:​​
    • 基于 Spring Boot 3.x。
    • 核心模块，​​直接连接数据库​​。
    • 核心业务逻辑在 tool 层实现，强调​​扩展性和解耦​​。
    • 提供 ​​HTTP API​​（用于控制、状态查询和聊天请求）。
    • 支持 ​​SSE (Server-Sent Events)​​: 允许客户端（如Cherry Studio）建立长连接，接收服务端的​​实时推送​​（状态更新、消息）。
    • 支持 ​​WebSocket​​: 提供​​全双工、低延迟、持久的连接​​。这是推荐的通信方式，客户端不仅可以实时接收消息，还能​​主动发送指令并立即获得响应​​。
    • 主要运行端口：9800 (可能包括SSE端点)，9801 (HTTP API), 9802 (WebSocket endpoint)。
  2. ​​MCP Client:​​
    • 也基于 Spring Boot 3.x。
    • 扮演 ​​MCP Client​​ 角色。
    • 核心职责：与​​大模型API（如DeepSeek）进行交互​​。
    • 文档提到两个客户端项目(根据Docker配置推断)：
      • mcp-client (可能只支持传统HTTP调用)
      • mcp-client-ws (明确支持WebSocket连接服务端)
    • ​​配置是关键​​：需要在 application-prod.yml 中配置目标大模型API的 api-key, base-url, 和 model。
    • 主要运行端口：9802 (WebSocket监听/mcp/ws)。

通信协议详解（重点）

  1. ​​HTTP：​​ 基础通信方式。用于：
    • 执行具体任务 (/mcp/mcpClient/chat?prompt=...)。例如：“查询章若楠用户信息”。
    • 获取工具列表 (/mcp/mcpClient/listTools)。
  2. ​​SSE (Server-Sent Events)：​​ 服务端单向推送协议。适用于服务端主动向客户端推送通知、状态的场景（如通过Cherry Studio监听）。连接方式：http://host:port/sse。
  3. ​​WebSocket (推荐)：​​ 全双工协议。优势在于：
    • ​​实时双向交互​​：客户端和服务端可以随时互相发送消息。
    • ​​低延迟​​：建立连接后消息传递非常快。
    • ​​连接持久化​​：一次连接可进行多次通信。 ​​这是项目推荐的连接方式。​​ 连接方式：ws://host:port/mcp/ws。

关键功能 - AI 大模型集成

  • 项目默认集成 ​​DeepSeek​​ 大模型API。
  • 需要用户自行申请和配置 ​​API Key​​。
  • 提供两种DeepSeek API来源：
    • 官方DeepSeek API：https://api.deepseek.com
    • 腾讯云版DeepSeek API：https://api.lkeap.cloud.tencent.com/v1 (提供免费额度：1,000,000 tokens)
  • 在 mcp-client-ws的配置文件中(application-prod.yml):
    • 指定 api-key (你的密钥)。
    • 指定 base-url (官方或腾讯云地址)。
    • 指定 model (如 deepseek-chat, deepseek-v3, deepseek-r1)。

部署说明 (Docker)

  1. ​​环境要求：​​ ​​必须使用 JDK 17 或更高版本编译和运行项目​​。
  2. ​​Docker Compose 部署：​​
    • 将项目编译打包好的jar文件放入 docker/app/ 下的对应目录（mcp-server/, mcp-client/, mcp-client-ws/）。
    • start.sh 脚本定义了启动顺序：先启动 mcp-server，再启动 mcp-client-ws。
    • 使用命令 docker-compose up -d mcp-server (或其他服务名)启动特定服务。
    • 使用 docker logs -f mcp-server 查看服务日志。
    • docker-compose.yml 文件定义了服务、网络、卷等配置。

前端与工具集成

  1. ​​Vue2 Chat Window：​​
    • 一个基于 Vue2 的聊天窗口前端实现。
    • 直接通过 ​​WebSocket​​ (ws://...) 连接到 mcp-client-ws 服务。
    • 使用方法：cd vue2-chat-window -> npm install -> npm run serve.
  2. ​​Cherry Studio：​​
    • 一个第三方AI助手工具/客户端（需要下载安装）。
    • 可以与本项目部署的MCP服务端连接。
    • 配置步骤：
      • 在 Cherry Studio 中配置模型信息。
      • ​​配置MCP连接信息​​：指定 MCP 服务端的HTTP或SSE端点（如 http://localhost:9800），以实现数据连接和指令控制。
      • 之后可以在Cherry Studio中调用连接到该MCP的工具。
  3. ​​JS测试脚本：​​ (node-ws-client/client.js)
    • 提供了一个Node.js脚本示例（需要使用 npm install 安装依赖）。
    • 该脚本通过​​WebSocket​​连接mcp-client-ws服务端点，用于测试和演示WebSocket交互。

Nginx配置建议

  • 提供了针对​​WebSocket反向代理​​的Nginx配置片段。
  • 核心配置：proxy_pass 指向后端WebSocket服务地址；proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade".
  • 这对于在生产环境通过标准端口提供WebSocket服务 (ws://yourdomain.com/mcp/ws 或更安全的 wss://yourdomain.com/mcp/ws) 至关重要。

总结要点

  1. ​​核心价值：​​ 实现​​MCP协议​​，作为标准化桥梁​​连接AI大模型与你现有的数据/工具系统​​。
  2. ​​技术栈：​​ Java + Spring Boot 3.x + Docker (JDK 17+ 强依赖)。
  3. ​​核心模块：​​
    • mcp-server: 提供API/SSE/WS端点，连接数据，实现业务逻辑。
    • mcp-client-ws: 与DeepSeek等大模型交互，并通过WebSocket与Server通信。
  4. ​​推荐通信：​​ ​​WebSocket​​ (ws://server:port/mcp/ws) 用于低延迟、全双工、实时交互。
  5. ​​AI集成：​​ 深度集成 ​​DeepSeek API​​，需要用户配置自己的Key。
  6. ​​部署方式：​​ 采用 ​​Docker Compose​​，需先打包Jar文件放入指定目录。
  7. ​​配套前端/工具：​​
    • Vue2实现的聊天窗口前端。
    • 可用第三方工具 ​​Cherry Studio​​ 连接并使用MCP服务。
    • 提供WebSocket测试脚本。

学习建议步骤

  1. ​​环境准备：​​ 确保安装 ​​JDK 17+​​, ​​Docker​​, ​​Docker Compose​​。
  2. ​​代码获取与阅读：​​ 获取项目源代码，重点阅读：
    • mcp-server 和 mcp-client-ws 模块的结构。
    • tool 层的核心业务逻辑实现。
    • WebSocket协议处理的代码位置。
  3. ​​编译与打包：​​ 学习如何编译项目并生成部署所需的 jar 文件。
  4. ​​Docker部署实战：​​
    • 按照文档指示放置 jar 文件。
    • 运行 start.sh 或 docker-compose up -d 启动服务。
    • 使用 docker logs 查看启动状态和日志。
  5. ​​API Key配置：​​ 申请DeepSeek API Key并正确配置到 mcp-client-ws的 application-prod.yml。
  6. ​​接口测试：​​
    • 使用 curl 或 Postman 测试 HTTP 接口。
    • 使用提供的 node-ws-client/client.js 测试 WebSocket 连接。
    • 运行 vue2-chat-window 测试前端效果。
  7. ​​理解协议交互：​​ 通过文档中的截图和测试，深入理解SSE和WebSocket的工作机制和数据流。
  8. ​​尝试Cherry Studio集成：​​ 安装Cherry Studio，配置它连接到你的MCP服务端进行实际操作体验。
