mall整合Redis实现缓存功能

前置知识：Spring Data Redis 的基础使用

整合Redis

  • 在pom.xml中添加Redis相关依赖；
  • 修改配置文件application.yml，添加Redis的连接配置；
  • 修改配置文件application.yml，添加Redis中自定义key的配置；
  • 添加Redis的Java配置，配置好RedisTemplate；
  • 添加RedisService接口用于定义一些常用Redis操作；
  • 注入RedisTemplate，实现RedisService接口。

实现验证码逻辑

这里以短信验证码的存储验证为例，具体逻辑如下：
生成验证码时，将自定义的Redis键值加上手机号生成一个Redis的key，以验证码为value存入到Redis中，并设置过期时间为自己配置的时间（这里为120s）。
校验验证码时根据手机号码来获取Redis里面存储的验证码，并与传入的验证码进行比对。

  • 添加UmsMemberController类，添加根据电话号码获取验证码的接口和校验验证码的接口；
  • 添加UmsMemberService接口；
  • 添加UmsMemberService接口的实现类UmsMemberServiceImpl。

使用Swagger的界面测试接口

访问Swagger的API文档对接口进行测试，访问地址：http://localhost:8080/swagger-ui/
