需要前置部署的一些服务

  • 1、本地部署大模型（使用 Ollama 的方式部署一下开源的 deepseek 蒸馏模型）
    • Ollama 是一个用于本地运行大型语言模型（如 LLaMA、GPT 等）的工具，支持通过 API 交互
  • 2、Redis 服务
  • 3、PGVector 数据库服务
    • 这里安装的是 基于 PostgreSQL 的向量数据库，用于存储和检索向量数据（如 AI 嵌入向量）
  • 4、Redis-Commander
    • Redis-Commander（Redis Admin） 是一个基于 Web 的 Redis 数据库管理工具，类似于轻量级的 Redis Desktop Manager 或 phpRedisAdmin。它的主要作用是提供一个可视化的界面来管理和操作 Redis 数据库
    • 这个服务感觉也不是太有必要一定需要安装

网络配置

  • 自定义网络: my-network（桥接模式）。
    所有服务（除 Ollama）通过此网络互联，确保容器间可通过服务名直接通信（如 redis 主机名指向 Redis 容器）。
