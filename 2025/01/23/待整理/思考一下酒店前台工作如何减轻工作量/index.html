需求

  • 1、统计未来七天内容的预定酒店房间的数量，并根据酒店的房型适当安排合适的人数，保证不会预定超过现存数量。
  • 2、针对统计线上、线下来源的实际收入，并做收入汇总。

输入来源

  • 手动输入（或者说调用 AI 的 API 接口后智能识别并转换为固定的数据，调用MQ进行发送处理）
  • 输入数据
    • 1、姓名
    • 2、性别
    • 3、预定房型
    • 4、居住日期
      • 开始日期
      • 结束日期
    • 5、房价（如果是美团和线下，获取是全部的价格，需要除以日期，并将价格计算到当天的日期中；如果是携程：获取是当天的数据）
    • 6、数据来源（下拉：美团、携程、线下）
  • 存储格式
    • 按照上面的格式存储即可，一个订单中的一天为一条数据，多天为多条数据

vue + springboot + mysql

企业微信推送机制

  • 当在前端界面点击已退房，房间状态会变为：待打扫，并将房间信息推送到 企业微信。
  • 定时触发，每过两个小时，如果还有未打扫的房间，会进行汇总推送消息发送到企业微信（另外一个群）
  • 当所有的房间变为已打扫，会触发机制：鼓励并汇报全部已打扫。
