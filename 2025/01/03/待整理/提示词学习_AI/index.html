温度

不难看出，temperature 的作用是来控制结果的多样性的，temperature 越高，结果的多样性越大，temperature 越低，结果的多样性越小。

当我们想要 ChatGPT 每次都给一个匹配度最高的结果时，可以讲 temperature 设置为 0，这将大概率得到概率最高的结果，多次发送 Prompt 得到的结果也大概率是一致的。

如果我们想要 ChatGPT 输出的内容更多样化，例如在 文案、创意素材 生成方面，就可以把 temperature 设置为 0.7 或 0.8 以获得更高的创造力。

Prompt编写两大原则

  1. Write clear and specific Instructions 编写清晰，具体的指令
  2. Give the model time to “Think” 给模型“思考”的时间

原则一 编写清晰，具体的指令 Write clear and specific Instructions
策略1：使用分隔符明确指示输入的不同部分 Use delimiters to clearly indicate distinct parts of the input

策略2: 要求一个格式化的输出 Ask for a structured output JSON,HTML

策略3: 要求模型检查条件是否已经满足 Ask the model to check whether conditions are satisfied.

策略4: 提供一些示例 “Few-shot” prompting

公司Stable Difussion生成效果： https://aigc-pc.dev-az.sheincorp.cn/#/home

原则二 给模型“思考”的时间 Give the model time to “Think”
策略1：给出完成任务所需的步骤，将复杂拆解步骤 Specify the steps requied to complete a task.

策略2: 指导模型在给出答案之前找出一个自己的答案 Instruct the model to work out its own solution before rushing to a conclusion.

模型局限性：幻觉(一本正经的胡说八道) Model Limitations: Hallucinations
“尽管语言模型在训练过程中接触了大量知识，但它并没有完美地记住所见的信息，因此，它并不能很好地知道自己的知识边界。这意味着它可能会试图回答一些晦涩难懂的话题，并且可能会编造听起来合理但实际上并不正确的东西。”

迭代式提示词开发 Iterative Prompt Development

迭代过程 Iteratice Process
1.Try something 先试一试
2.Analyze where the result does not give what you want. 分析未达到预期结果的原因
3.Clarify instructions, give more time to think 阐明指令，给予更多思考时间
4.Refine prompts with a batch of examples 用一批示例来完善提示

1.编写一个符合两个原则的提示词
2.运行并查看结果
3.分析未达到预期结果的原因
4.阐明指令，给予更多思考时间/用一批示例来完善提示
5.回到第一步
