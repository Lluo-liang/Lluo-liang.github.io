报错2:

你遇到的 EACCES 权限错误是由于 npm 缓存目录 (~/.npm) 的所有权被错误地设置为 root（可能之前使用 sudo 运行过 npm 命令），而当前用户没有权限修改该目录。

修复缓存目录权限(复制报错中的命令)

检查 .npm 目录的所有权是否已变更：

输出中的 owner 和 group 应显示为你的当前用户（而非 root）

报错3

  • 权限问题：
    /usr/local/lib/node_modules 是系统级目录，默认需要 root 权限才能写入。普通用户无权在此目录下创建文件或文件夹。

  • npm 默认配置问题：
    npm 的全局安装路径默认指向 /usr/local/lib/node_modules，而非用户目录，导致权限冲突

解决方法：第三种方式 配置 npm 使用用户目录（推荐）
