Docker 常用命令

容器管理

  1. 启动容器

    • 示例：docker run -d -p 80:80 nginx
      （后台运行 nginx 容器，映射本机 80 端口到容器的 80 端口）

  2. 列出容器

    • 默认显示运行中容器：docker ps
    • 显示所有容器（含已停止）：docker ps -a

  3. 停止容器

    • 示例：docker stop my_container
      （停止名为 my_container 的容器）

  4. 删除容器

    • 示例：docker rm my_container
      （删除已停止的容器，需添加 -f 强制删除运行中的容器）

  5. 查看容器日志

    • 示例：docker logs -f my_container
      （-f 参数可实时追踪日志）

  6. 重启容器

    • 示例：docker restart my_container

镜像管理

  1. 列出本地镜像

    • 示例：docker images
      （显示所有本地镜像，-q 仅显示镜像 ID）

  2. 拉取镜像

    • 示例：docker pull nginx:alpine
      （拉取指定版本的 nginx 镜像）

  3. 构建镜像

    • 示例：docker build -t my_app:v1 .
      （基于当前目录 Dockerfile 构建镜像并打标签）

  4. 删除镜像

    • 示例：docker rmi my_app:v1
      （需先删除依赖该镜像的容器）

网络管理

  1. 列出网络

  2. 创建自定义网络

    • 示例：docker network create my_network
      （默认创建 bridge 类型网络）

  3. 删除网络

    • 示例：docker network rm my_network

卷管理

  1. 创建数据卷

    • 示例：docker volume create db_data

  2. 列出数据卷

  3. 删除数据卷

    • 示例：docker volume rm db_data

其他常用命令

  1. 查看 Docker 版本

  2. 查看 Docker 系统信息

  3. 查看详细信息

    • 示例：docker inspect my_container
      （查看容器/镜像/卷的元数据）

  4. 进入运行中的容器

    • 示例：docker exec -it my_container bash
      （以交互模式进入容器执行命令）
