索尼 A6700 新手使用教程：从曝光三角到实战操作

索尼 A6700 是一台功能强大的 APS-C 旗舰微单，2600 万像素、AI 实时追踪对焦、4K 120p 视频、五轴防抖……参数亮眼，但拿到手后第一件事不是翻菜单，而是弄懂怎么控制曝光。

这篇教程从最基础的曝光原理讲起，一步步带你理解相机档位、物理操控，再到实战拍摄流程，适合刚入手 A6700 或者刚接触可换镜头相机的朋友。

一、曝光铁三角：光圈、快门速度、ISO

所有手动摄影的基础都建立在这三个参数之上，它们共同决定了照片的亮度，同时各自带来不同的画面效果。

光圈（Aperture）

控制镜头的进光量和景深（背景虚化程度）。

  • 数字越小（如 F1.4），光圈越大，进光越多，背景越虚化
  • 数字越大（如 F16），光圈越小，进光越少，前后景都清晰

可以把光圈想象成瞳孔：暗处瞳孔放大（大光圈），亮处瞳孔缩小（小光圈）。

快门速度（Shutter Speed）

控制传感器的曝光时间和动态模糊效果。

  • 速度越快（如 1/2000 秒），能凝固高速运动的瞬间
  • 速度越慢（如 1 秒），运动物体会产生轨迹或拉丝效果

ISO（感光度）

控制传感器对光线的敏感程度。

  • 越高（如 ISO 3200）画面越亮，但噪点也越多，画质下降
  • 越低（如 ISO 100）画质越干净，但需要更多光线

A6700 的高感表现在 APS-C 中属于优秀水准，ISO 6400 以内噪点控制良好，日常使用可以放心。

三者的关系

三个参数像跷跷板：调亮一个，就需要调暗另一个来保持曝光平衡。摄影的艺术在于根据拍摄意图选择优先控制哪个参数，让其余参数去配合。

二、A / S / M 三大档位详解

模式转盘是 A6700 机身顶部左侧的物理旋钮，拨到对应档位即可切换拍摄模式。

A 档 — 光圈优先模式

你控制 相机控制
光圈值、ISO 快门速度

核心目的：控制景深（虚化程度），是最常用的拍摄模式。

适用场景：

  • 人像 / 静物：大光圈（F1.4 ~ F2.8）获得柔美的背景虚化，突出主体
  • 风光 / 建筑：小光圈（F8 ~ F16）获得从近到远都清晰的大景深
  • 日常扫街：专注构图和景深，曝光交给相机，反应迅速

A6700 操作提示：

  • 使用前拨轮（镜头后方，食指位置）快速调整光圈值
  • 注意观察相机自动匹配的快门速度，若低于安全快门（约 1/焦距 秒），可能导致手抖模糊，此时应提高 ISO
  • 推荐设置：菜单 → 曝光/颜色 → ISO 自动最小速度，设定一个安全快门下限，相机会自动提升 ISO 来保证快门速度

S 档 — 快门优先模式

你控制 相机控制
快门速度、ISO 光圈值

核心目的：控制动态模糊（凝固瞬间或创造拖影效果）。

适用场景：

  • 运动 / 儿童 / 宠物：高速快门（1/1000 秒以上）凝固瞬间动作
  • 追随拍摄：较慢快门（1/30 秒左右）让背景拉丝，主体相对清晰
  • 水流 / 光轨：慢速快门（1 秒或更长）拍出丝绸般的流水或灯光轨迹
  • 视频拍摄：快门速度固定在帧率 2 倍的倒数（如 30fps 视频用 1/60 秒），保证画面流畅

A6700 操作提示：

  • 使用后拨轮（机身顶部右侧，拇指位置）调整快门速度
  • 光线不足时高速快门会导致曝光不足（屏幕变暗），需提高 ISO
  • 光线充足时慢速快门会让相机自动缩小光圈，注意景深变化

M 档 — 全手动模式

你控制 相机控制
光圈、快门速度、ISO 无（仅提供曝光参考指示）

核心目的：完全掌控曝光，应对复杂或固定光线环境。

适用场景：

  • 影棚 / 闪光灯拍摄：固定参数保证每张曝光一致
  • 延时摄影 / 光绘：需要完全稳定的曝光参数
  • 逆光 / 剪影 / 夜景：自动模式容易误判，手动更精准
  • 学习曝光：理解三者关系的最佳练习模式

A6700 操作提示：

  • 前拨轮控制光圈，后拨轮控制快门速度，按下后拨轮调出 ISO 菜单
  • 屏幕下方的曝光指示器（±标尺）是你的参考：指针归零为标准曝光，往”+”走为过曝，往”-”走为欠曝
  • M 档下开启 ISO 自动：手动控制光圈和快门，相机自动调整 ISO，非常适合快速变化的场景
  • 充分利用 A6700 的实时取景，所见即所得，直观看到参数调整带来的明暗变化

档位速查表

模式 你控制 相机控制 核心目的
A 档 光圈、ISO 快门速度 控制景深（虚化程度）
S 档 快门速度、ISO 光圈 控制动态模糊（凝固或拖影）
M 档 光圈、快门、ISO 无（仅参考） 完全控制曝光

三、A6700 物理操控指南

拿起相机，手指该放在哪里？A6700 的操控主要通过两个拨轮和一个控制转盘完成。

拨轮与按键布局

操控件 位置 功能
前拨轮（主控拨轮） 镜头后方，食指位置 调整光圈
后拨轮（后指令拨轮） 机身顶部右侧，快门按钮后方 调整快门速度
按下后拨轮 垂直按下后指令拨轮 调出 ISO 选择菜单
ISO 物理按键 后拨轮下方 同上，调出 ISO 菜单
控制转盘 机身背面，带方向键的大转盘 调整曝光补偿

手指位置速记

  • 右手食指：控制前拨轮（光圈）+ 按快门
  • 右手拇指：控制后拨轮（快门速度）+ 按下调出 ISO
  • 眼睛：时刻观察屏幕 / 取景器中参数变化和画面明暗

使用前确保模式转盘在 P / A / S / M 档位。绿色 Auto 档为全自动，无法手动调整参数。

四、拍摄决策流程

理解了每个参数怎么调，更重要的是按什么顺序、为什么这样调。

第一步：选择拍摄模式

根据你的首要创作意图来决定：

你想要的效果 选择模式 优先调整
控制背景虚化 A 档 光圈
凝固或拖影运动 S 档 快门速度
完全掌控 / 复杂光线 M 档 三者都调

第二步：设置 ISO — 遵循”尽可能低”原则

  • 在保证画面亮度足够的前提下，ISO 越低越好
  • 推荐起步：ISO 自动，或手动设为 100 ~ 200
  • 如果快门速度不够快（A 档）或光圈已到极限（S 档），再逐步提高 ISO

各档位 ISO 调整参考：

  • A 档：快门速度低于 1/焦距 → 提高 ISO
  • S 档：光圈已开到最大仍欠曝 → 提高 ISO
  • M 档：曝光标尺偏左（欠曝）→ 提高 ISO

第三步：曝光补偿微调（A / S / P 档）

即使相机自动计算了曝光，你仍然可以用曝光补偿快速调整整体明暗：

  • 操作：转动机身背面的控制转盘
  • 拍雪景：相机容易拍灰，增加曝光补偿（+EV）让雪变白
  • 拍暗调氛围：减少曝光补偿（-EV）让画面更沉稳

曝光补偿是新手拍出”感觉对了”的照片最快捷的工具，不要忽视它。

五、实战案例 — A 档日常人像拍摄

把上面的知识串起来，以最常用的 A 档为例，走一遍完整的拍摄流程：

  1. 转模式转盘到 A
  2. 用前拨轮设置光圈：拍人像，转到 F2.8
  3. 设置 ISO：先设为自动，或手动设为 200
  4. 半按快门对焦，观察参数：发现快门速度显示为 1/30 秒（有手抖风险）
  5. 提高 ISO：按下后拨轮，将 ISO 从 200 提高到 800，快门速度变为 1/125 秒（安全了）
  6. 拍摄并回看：觉得整体有点暗
  7. 调整曝光补偿：转动控制转盘，往”+”方向调 +0.7EV
  8. 再次拍摄，得到满意照片

六、A6700 推荐初始设置

刚拿到相机，建议做以下基础设置，可以让后续拍摄更顺手：

设置项 推荐值 说明
文件格式 RAW + JPEG RAW 保留最大后期空间
对焦区域 广域 + 追踪 配合 AI 对焦，适合大多数场景
对焦主体 人物（或动物） 根据常拍题材选择
ISO 自动上限 6400 或 12800 根据你对噪点的接受程度
ISO 自动最小速度 标准 或 快 防止手抖
创意外观 SH（柔和高对比） A6700 的经典直出色彩
网格线 三分法 辅助构图

七、给新手的建议

  1. 从 A 档开始：最直观、最常用。先学会通过光圈控制虚化，同时观察快门速度的变化，理解两者的联动关系
  2. 尝试 S 档：去拍运动物体，体验快门速度对画面的决定性作用
  3. 挑战 M 档：在固定光线的房间里，手动调整三个参数让曝光指示器归零，这是理解曝光的必经之路
  4. 善用 ISO 自动：在 A 档和 S 档下开启 ISO 自动并设合理上限，只需专注一个核心参数，大大简化操作
  5. 相信你的屏幕：A6700 的 EVF 和翻转屏素质很高，实时预览非常准确。大胆尝试，所见即所得
  6. 多拍多看：不要怕拍废片。每次拍完回看照片时留意 EXIF 信息（光圈、快门、ISO），久了自然形成直觉
