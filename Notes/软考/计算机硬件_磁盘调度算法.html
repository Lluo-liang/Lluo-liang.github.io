什么是磁盘调度算法

磁盘结构与数据存储：

  1. 磁盘有正反两个盘面。
  2. 每个盘面有多个同心圆（磁道）。
  3. 每个磁道被划分为多个扇区，数据存储在扇区中。

数据读取过程：

  1. 磁头首先要寻找到对应的磁道。
  2. 然后等待磁盘周期旋转到指定扇区，才能读取数据。
  3. 这过程会产生两部分时间：寻道时间和等待时间。

磁盘有正反两个盘面，每个盘面有多个同心圆，每个同心圆是一个磁道，每个同心圆又被划分为多个扇区，数据就被存放在一个个扇区中。

磁头首先要寻找到对应的磁道，然后等待磁盘进行周期旋转，旋转到指定的扇区，才能读取到对应的数据，因此，会产生寻道时间和等待时间。

公式为：存取时间=寻道时间+等待时间（平均定位时间+转动延迟）。

注意：寻道时间是指磁头移动到磁道所需的时间；等待时间为等待读写的扇区转到磁头下方所用的时间。

磁头位置示意图

  1. 数据操作：目标扇区到达磁头下方后，进行数据读取/写入操作。
  1. 磁头移动到磁道3：寻道过程，耗时。
  2. 磁盘旋转：等待特定扇区（△）移动到磁头下方，耗时。
  3. 数据操作：访问扇区△的数据。

寻道并不是扫描整个磁盘，而是确保磁头在一个合适的磁道上停留，等待磁盘旋转到正确扇区进行数据操作。

公式

存取时间=寻道时间+等待时间

其中：

  • 寻道时间：磁头移动到目标磁道所需的时间。
  • 等待时间（转动延迟）：扇区旋转到磁头下方所需的时间。

调度算法

调度算法（需重点调度 寻道时间，因为它耗时最长）：

  1. **先来先服务 (FCFS)**：
    • 根据请求访问磁盘的顺序进行调度。
  2. **最短寻道时间优先 (SSTF)**：
    • 优先调度与当前磁道最近的请求，最短化每次的寻道时间。
    • 可能会产生“饥饿”现象，远处的请求可能永远无法被访问。
  3. **扫描算法 (SCAN)**：
    • 也称“电梯算法”，磁头在磁盘上双向移动，选择离当前磁道最近的请求，并且与磁头当前的移动方向一致。
    • 磁头按一个方向（里向外或外向里）完全移动到磁盘边缘后才掉头。
  4. **单向扫描调度算法 (CSCAN)**：
    • 只做单向移动，磁头只能从里向外或从外向里移动。

练习题

考试真题：

第一题

假设某磁盘的每个磁道划分成11个物理块，每块存放1个逻辑记录。逻辑记录 R0，R1,···,R9,R10存放在同一个磁道上，
记录的存放顺序如下表所示：

如果磁盘的旋转周期为33s,磁头当前处在R0的开始处。若系统使用单缓冲区顺序处理这些记录，每个记录处理时间为3ms,则处理这11个记录的最长时间为（)；若对信息存储进行优化分布后，处理11个记录的最少时间为（)。

  • A.33ms

  • B.336ms

  • C.366ms

  • D.376ms

  • A.33ms

  • B.66ms

  • C.86ms

  • D.93ms

解析：

题目重述：

  • 磁盘每个磁道有11个物理块，每块存放一个逻辑记录（R0, R1, …, R10）。
  • 读取旋转周期为33ms。
  • 读取每个记录时间为3ms。
  • 当前从R0开始。
  • 使用单缓冲区顺序处理，处理时间为3ms。

问题1：处理这11个记录的最长时间是多少？ 问题2：优化后处理11个记录的最少时间是多少？

分析

  1. 处理每个记录的时间：

    • 旋转周期：33ms
    • 每个块的旋转时间：33ms / 11 = 3ms
    • 处理每个记录的时间 = 读取时间 + 处理时间 = 3ms + 3ms = 6ms

  2. 最长时间：

    • 处理完R0后，磁头在3ms旋转到R1的位置，但实际已经用了6ms（包括读取与处理），所以需要重新等待一个33ms的旋转周期。
    • 对于R1：等待时间 = 10 * 3ms（一个旋转周期截至）+ 3ms（读取时间）+ 3ms（处理时间）= 36ms。
    • 依次类推，处理完剩下的10个记录，每个记录都需要额外等待一个完整的旋转：
      总时间=6ms(R0)+10×36ms(R1−R10)=6ms+360ms=366ms

    因此最长时间为 366ms，答案是 C。

图示过程 (部分)：

  1. R0 -> 等待3ms -> 读取3ms -> 处理3ms = 6ms
  2. R1 -> 等待到完整旋转周期 = 33ms全集 -> 读取3ms -> 处理3ms
    • …重复…

优化存储后：

采用间隔存储方式，使得每个记录读取和处理的时间能被紧凑地利用。

  • 优化原理：让每个块的数据分布在不同位置上，避免重新旋转周期，理论上可以在两个旋转周期内完成所有读取。

    总时间=2×33ms=66ms总时间=2×33ms=66ms

答案是 B。

详细步骤：

  1. 非优化：
    • 每个记录读取和处理（等待+处理）：全顺序：要额外的一轮盘片移动等待时间
  2. 优化后：
    • 利用每块的空间：设置和间隔存储使得处理时间正好覆盖下一个需要处理数据所在位置

通过详细分析和计算，可以确认两种情况最终的处理时间。

第二题

在磁盘调度管理中，应先进行移臂调度，再进行旋转调度。假设磁盘移动臂位于21号柱面上，进程的请求序列如下表所示。如果采用最短移臂调度算法，那么系统的响应序列应为( )。

  • A.②⑧③④⑤①⑦⑥⑨
  • B.②③⑧④⑥⑨①⑤⑦
  • c.①②③④⑤⑥⑦⑧⑨
  • D.②⑧③⑤⑦①④⑥⑨

解析

最短移臂调度算法：在该算法中，每次选择距离当前位置最近的请求进行处理，从而实现最短寻道时间

具体步骤说明

输入解析

初始位置：21号柱面

请求序列：

  1. 17号柱面，扇区9
  2. 23号柱面，扇区3
  3. 23号柱面，扇区6
  4. 32号柱面，扇区5
  5. 17号柱面，扇区4
  6. 32号柱面，扇区10
  7. 17号柱面，扇区9
  8. 23号柱面，扇区4
  9. 38号柱面，扇区8

计算最短移臂调度顺序

  1. 初始在21号柱面，距离最近的是23号柱面：
    • 23号柱面（②）
    • 23号柱面（③）
    • 23号柱面（⑧）
  2. 当前在23号柱面，接下来距离最近的是17号柱面和32号柱面：
    • 17号柱面（①、⑤、⑦；三者在17号柱面内磁头位置的先后无关紧要）
    • 32号柱面（④、⑥；原理同上）
  3. 当前在17号柱面，距离近的为：
    • 17号柱面（①、⑤、⑦）
  4. 处理完17号柱面后，转向32号柱面的位置：
    • 32号柱面（④、⑥）
  5. 最后，处理38号柱面：
    • 38号柱面（⑨）

总结：

根据以上分析，正确的响应顺序为：②, ③, ⑧, ①, ⑤, ⑦, ④, ⑥, ⑨，答案是 D。
